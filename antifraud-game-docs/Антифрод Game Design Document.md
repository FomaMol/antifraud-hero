# Антифрод Hero

## High concept

игра на внимательность (point & click), где необходимо анализировать входящие сообщения, звонки и транзакции, чтобы отличить легитимные действия от попыток мошенничества. Вдохновились игрой ****[Papers, Please - Trailer](https://www.youtube.com/watch?v=_QP5X6fcukM)



## Core loop

1. **Поступил запрос** (сообщение/транзакция)
2. **Анализ**: игрок открывает 1–2 инструмента проверки (встроенные “Табы”)
3. **Вердикт**:
    - **Подтвердить** (если всё ок)
    - **Заблокировать** (если мошенничество)
    - *(опционально для MVP)* **Запросить инфо** (если данных не хватает)
4. **Результат**: +1 / -1 балл в зависимости от исхода + короткий фидбек “почему правильно/неправильно”.

## Сценарии

Используем 5 типов кейсов на старте

1. **“Мам, я в беде”**
    
    Признаки: срочность, просьба перевести на чужую карту, странные формулировки. 
    
    Проверки в MVP: “проверка получателя” (совпадает ли с контактами/родством в базе).
    
2. **Фишинг “от банка”**
    
    Признаки: домен-клон, ошибки, запрос CVV/данных. 
    
    Проверки в MVP: “сканер ссылок” (показывает истинный домен/подмену символов).
    
3. **“Гос. штрафы”**
    
    Признаки: давление “срочно”, оплата на личный номер/по СБП. 
    
    Проверки в MVP: “официальная база постановлений” (номер существует/нет).
    
4. “**Ложная реклама**”
    
    Признаки:  Обещания богатства за небольшие вложения, эксклюзивность, срочность, игра на жажде наживы
    
    Проверки в MVP: Дополнительные уточнения
    
5. **“Настоящие обращения”**
    
    Признаки: иногда могут выглядеть подозрительно и быть похожими на кейсы из “мам я в беде” или другие категории но являются настоящими. 
    
    Проверки в MVP: После проверок по инструментам и отсутствию несовпадений выявляются кейсы без подвоха
    

 **~ План на 10–20 кейсов:**

- 10 простых (очевидный фишинг)
- 5 средних (ошибка в ссылке + правдоподобный текст)
- 5 “пограничных” (есть 1 красный флаг, но без проверки не ясно)
    
    Это сохраняет идею “день 1–2 простые, дальше чуть сложнее”, но без усложнений.
    

## Основные сущности

**Кейс**

- Тип кейса: Настоящее обращение / Фишинг / Реклама / Фэйк гос.структур / Криптоскам(любой иной скам с обещаниями богатства)
- “входящее” (текст + метаданные: отправитель, номер/почта, ссылка, сумма/получатель, ip и т.д.)
- Статус кейса - настоящее /обманка
- подсказка/разбор (“почему”) по каждому кейсу свой текст в зависимости от того что выдает обман или общее замечание на каждый вид несостыковок (общий пост для неверного ип, общий пост для несовпадения домена и т.д.)

**Табы (Инструменты выявления мошенничества)**

Типы табов:

- Tab 1: **Сканер ссылок** (проверяет любую ссылку в обращении на безопасность)
- Tab 2: **Проверка получателя/контакта** (Сопоставление с реальными данными)
- Tab 3: **Официальная база** (для “штрафов” и взаимодействия с официальными или иными публичными структурами)

---

- что показываем игроку (например: “домен: g00gle.com → подмена символов” или окончание сайта на .com.net )
- Табов можно сделать больше, открывать их не все сразу, а по одному за каждый “день” в который входит n рассмотренных кейсов

## Экраны и UX-флоу

### Экран: Loading / Preload (опционально)

- Логотип + “Загрузка…”

### Экран: Главное меню

**UI:**

- Заголовок игры
- Кнопки:
    - **Начать смену**
    - *(опционально)* “Как играть”
    - *(опционально)* “Настройки” (звук/язык — можно вообще убрать)

**Взаимодействие:** по клику

### Экран: Как играть

**UI:**

- 3 шага с иконками:
    1. Открой кейс
    2. Проверь факты инструментами
    3. Вынеси вердикт
- Кнопка **“К работе”**

### Экран: Рабочий стол (кор геймплей)


**Композиция (простая, без “настоящих окон ОС”):**

1. **Левая колонка: Очередь кейсов**
    - список карточек (кейс #, иконка типа, кратко: “SMS / Email / Перевод”)
    - текущий кейс подсвечен
2. **Центр: Окно “Входящее”**
    - “Сообщение / Транзакция” (основной текст)
    - блок метаданных: отправитель, контакт, сумма/получатель, ссылка (если есть)
    - выделение красным “подозрительных” слов по клику (почта, цифры, адрес и т.д.) (опционально, через подсказку (ограниченное кол-во, или через табы)
3. **Правая колонка: Инструменты проверки (табы)**
    - Tab 1: **Сканер ссылок**
    - Tab 2: **Проверка получателя/контакта**
    - Tab 3: **Официальная база** (для “штрафов”)
    - в каждом табе: кнопка **“Проверить”** → ниже показывается результат (текст + “OK/ALERT” бейдж)
        - 1 Вариант - как в ориге нужно после нажатия кнопки проверить еще раз кликнуть по конкретной области которую проверяем (прим. нажимаем “проверить” в разделе ip, затем надо кликнуть на ip
        - 2 Вариант - казуальный, по клику на “проверить” сразу подсвечиваем красным/зеленым проверяемую инфу с кратким поп-ап текстом Совпадение/Несовпадение
4. **Нижняя панель: Решение**
    - **Подтвердить**
    - **Заблокировать**
    - **Уточнить** - запрос доп-инфы для кейсов в которых не хватает вводных данных (можно использовать в качестве “бустера” подсказки с ограниченным количеством

**Ключевое взаимодействие игрока:**

- клик по кейсу в очереди (или авто-переход “Следующий” после решения)
- клик по инструменту или инструментам (tab) → “Проверить”
- принятие решения кнопкой
- мгновенный фидбек “верно/ошибка” + краткая причина

### Экран: Результат по кейсу (поп-ап на несколько секунд или до клика игроком)

**UI:**

- “Верно” / “Ошибка”
- 1–2 строки объяснения (из данных кейса)
- кнопка **“Следующий кейс”** (или авто через n сек)

### Экран: Итоги смены

**UI:**

- Статистика: “Проверено”, “Ошибок”, “Точность %”
- Оценка смены: Отлично/Хорошо/Неплохо/Плохо
- Кнопки:
    - **Следующий уровень**
    - **попробовать еще**

(В зависимости от успешности)

## Правила

- За правильное решение: +1 “верно”
- За ошибку: +1 “ошибка”
- Для перехода на следующий уровень необходимо набрать n очков (соответствует оценке “Хорошо”.
- У игрока всегда доступна одна кнопка, - **Следующий уровень** или **Попробовать еще.** В зависимости от успешности уровня
- Когда игрок прошел все уровни он получает финальный поп-ап с поздравлениями. ****
